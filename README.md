# Vectora 矢量路径工具

安装：Node.js 22 环境下执行 `npm ci`。

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:8119。

## 参数化重复器（Repeater）

选中一个图形作为原件后，可在左侧创建三类参数化重复器：

- **沿曲线（path）**：以另一条路径为轨道，按弧长均布副本，支持起始偏移、弧长间距和切线跟随。末端不足一个整步时可选：
  - `blank` 留空：保持设定间距，超出轨道的槽位不渲染；
  - `fit` 调整间距：自动把步距改为 `可用长度 / (数量-1)`，均匀铺满轨道。
- **环形（ring）**：围绕中心点按起始角/扫掠角排布，整环首尾相接，可做法线朝向跟随。
- **二维网格（grid）**：列数、行数、双向间距与整体旋转联动，`count = cols × rows`。

### 设计要点

- **参数化而非复制像素**：规则只保存参数与原件引用，副本在渲染时由源图形的真实贝塞尔节点经仿射变换生成。修改原件，所有副本实时跟随。
- **快速预览大量副本**：每个重复器在画布上只渲染为一条合并的 SVG path，DOM 节点数与副本数量无关（数百副本仍是单节点），但几何数据是完整矢量路径。
- **单副本例外**：在画布上点击任一副本即可单独选中，调整位移、旋转、缩放或隐藏。例外按**稳定槽位 id**（路径/环形为线性序号，网格为 `列,行`）存储，修改数量后例外仍锚定同一逻辑位置，不会错套到相邻副本。
- **展开为真实层级**：「展开为节点」把每个可见副本实体化为独立 `Shape`（独立节点数据、同一实际分组），不再是虚拟实例；展开动作进入历史栈，撤销可完整恢复重复器规则、参数与全部例外。
- **存档与导出**：
  - 自动保存与 JSON 项目归档（Archive ↓ / Import ↑）完整保留规则和例外；
  - SVG 导出包含渲染出的真实路径分组，并在 `<metadata>` 中嵌入完整规则 JSON，可通过 Import 读回关联。

## 测试

- `npm run typecheck`：类型检查
- `npm run test:unit`：纯逻辑单测（弧长分配、槽位稳定性、展开实体化）
- `npm run test:components`：组件级集成测试（面板交互、历史恢复、存档、SVG 往返）
- `npm run test:app`：完整 App 挂载冒烟
- `npm test`：依次执行以上全部测试
